## About This Project

This project explores the transformation of genomics research from traditional wet-lab biology to modern AI-driven computational genomics.

While originally developed for the HackBio AI for Genomics Internship, this project also serves as part of my professional portfolio, demonstrating my ability to:

* Communicate complex scientific concepts clearly
* Write reproducible code in R
* Apply bioinformatics and AI concepts to genomics research
* Bridge healthcare, laboratory science, and data analytics

## Key Topic

The essay discusses how artificial intelligence, machine learning, and computational tools are transforming genomics research, enabling scientists to analyze vast genomic datasets and accelerate biological discovery.
